# Guia do Usuário - PressureIQ

## Acesso ao Sistema
Acesse o Dashboard em: `http://localhost:3001` (ou `https://iqpressure.online` em produção).

## Login e Cadastro
1. **Criar Conta**: Clique na aba "Criar Conta", preencha seus dados (Email, Nome, WhatsApp) e crie uma senha.
2. **Login**: Use seu email e senha para entrar.
3. **Planos**: Escolha entre o plano **Pro** (Escanteios) ou **Max** (Escanteios + Cartões + Bot).

## Funcionalidades Principais

### Dashboard de Jogos Ao Vivo
- **Tabela de Jogos**: Lista todos os jogos monitorados ao vivo.
- **Métricas**:
  - `Pressure Score`: Índice de pressão calculado por IA.
  - `Appm1/Appm2`: Ataques perigosos por minuto.
  - `ExG`: Expectativa de gol.
- **Sinais**: Alertas visuais quando um jogo atinge os critérios de aposta.

### Planos e Assinaturas
O sistema gerencia assinaturas via **Asaas**. O pagamento é processado via PIX ou Boleto.
- A liberação do acesso é automática após a confirmação do pagamento.
- Você será adicionado automaticamente aos grupos de sinais no WhatsApp.

### Grupos de WhatsApp
- **Grupo Geral (Pro/Max)**: Recebe sinais de escanteios e pressão.
- **Grupo de Cartões (Max)**: Recebe sinais exclusivos de cartões e arbitragem.
